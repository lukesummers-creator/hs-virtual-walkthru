# Workbench Inbox (single drop zone)

Drop anything you want Mac to process here:

- **Path:** `/Users/lrs/clawd/_INBOX/`

## How routing works
- The **Telegram channel/thread** where you say “check inbox” provides the top-level project context (Proposals vs The Pit vs Groceries vs Passport/Sheets/Migration).
- Mac then routes items into either:
  - **Brain** (`/Users/lrs/mac-brain`) for text-based rules/SOPs/templates/lookup tables/indices, or
  - **Workbench** (`/Users/lrs/clawd`) for binary/job intake artifacts (zips/pdfs/xlsx/photos).

If routing is ambiguous (training vs job intake; which job/quest/week), Mac will ask a single clarifying question before moving anything.
