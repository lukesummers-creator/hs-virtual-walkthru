# Meal Planning Principles (Summers)

## Weekly structure
- Default = **5 dinners/week**.
- Start with a draft, then tighten based on:
  - nights out / late meetings
  - kid activities
  - leftovers / push-to-next-week items
  - freezer/fridge reality

## Constraints
- **Gluten-free by default**.
- Kids generally **don’t like spicy**.
- Luke + Ashley do like spice, so prefer **configurable heat** meals:
  - spicy components optional
  - sour cream / cheese / mild base to neutralize

## Variability / rotation goal
- Aim for variety across proteins + sides.
- When repeating a "pattern" (e.g., steak + potato + green veg), vary the sides week-to-week:
  - baked potato → sweet potato
  - green beans → asparagus / broccoli / salad
  - switch seasoning profile (lemon-garlic vs taco vs italian)

## “No hard no’s (yet)”
- No hard exclusions currently; capture hard no’s as they emerge.
