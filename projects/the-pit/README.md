# The Pit

The Pit is our **sandbox + launchpad**.

We use it to:
- spin up **side quests** with clean context
- capture decisions/notes so nothing gets lost
- **deploy** outcomes into existing projects OR **promote** a quest into a new project

## Working rules
- Every quest lives in `projects/the-pit/QUESTS/<slug>/`
- Each quest has:
  - a clear **Definition of Done**
  - a running **worklog** (decisions + why)
  - an explicit **deploy target** (where it lands when shipped)
- **Luke is the deploy authority**: I can draft + prep patches, but we ship when Luke says so.

## File layout
- `INDEX.md` — Active Stack + Backlog + Shipped
- `INBOX.md` — raw idea dump (triage into quests)
- `TEMPLATES/` — quest + deploy templates
- `QUESTS/` — one folder per quest
