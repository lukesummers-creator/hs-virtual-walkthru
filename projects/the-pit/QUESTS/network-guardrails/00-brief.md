# 00 — Brief (network-guardrails)

## Problem
Mac’s network expanded beyond Luke ↔ Mac to include Ashley. That increases risk of:
- context bleed (wrong assumptions from the wrong thread)
- authority bleed (someone other than Luke steering official artifacts)
- preference bleed (mixing personal/proposal styles across people/projects)
- mis-sends (sending info to the wrong chat/person)

## Goal / Definition of Done
A clear, lightweight system that:
- keeps official project artifacts controlled by Luke
- keeps Ashley collaboration possible without letting noise/authority leak into docs
- makes it hard to accidentally share the wrong info in the wrong place
- is easy to follow and enforce (checklists + defaults)

## Non-goals
- Heavy bureaucracy
- Perfect security model

## Constraints
- Telegram group contexts can be noisy if we ever add people
- System/config changes require explicit Luke approval
