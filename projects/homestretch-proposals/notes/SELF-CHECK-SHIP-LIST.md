# Self-check before “ship” (Proposal Engine)

This is the last step before Mac says anything is "ready".

Luke rule: After intake there is no “bones.” Everything must have meat on it (pricing-pass ready).

## Universal
- [ ] Did I apply new rules globally where they logically apply (not just the first instance)?
- [ ] Did I backcheck existing artifacts immediately (current active job), re-copy Drive drafts, and summarize what changed?
- [ ] No ambiguous phrases like **“as scoped”**.

## Proposal Pack (7540-style)
- [ ] Has required sections: email send (or explicit note that it’s not used), paint triangle, handyman, PandaDoc scope blocks, confidence/questions.
- [ ] Paint triangle is complete: Cost Plus + Room Rate + $/sf + Recommendation (no TBDs).
- [ ] Repair drivers are pulled forward from notes (tiers, water damage, wallpaper/plaster, mobility-aid scrapes, etc).
- [ ] Handyman section is notes-driven when picklists are wrong/limited (assumptions stated).

### Paint pricing blocks schema
For each point (Cost Plus / Room Rate / $/sf / Recommendation):
- [ ] Exactly 4 lines in this order:
  1) Customer Price
  2) Materials Cost
  3) Labor Cost
  4) Customer Price $/sf @ WorkedFloorSF
- [ ] Count of blocks == number of points.

### Option split integrity (when we split out a room/service)
- [ ] Option A room list matches Option A PandaDoc scope section.
- [ ] Option B room list matches Option B PandaDoc scope section.
- [ ] No Option A rooms accidentally appear under Option B scope.

### Handyman alignment
- [ ] One task per line (split multi-task entries into separate bullets).
- [ ] Minutes list line breaks == SCOPE DETAILS bullet count (1:1).

### PandaDoc client-facing copy check
- [ ] PandaDoc scope language contains no internal field-capture notes (e.g., “placeholder”, “excluded”, “FastField glitch”).
- [ ] PandaDoc scope language is plain text only (no bold/italics/markdown markers like **, *, _).
- [ ] No ambiguous phrases like “as scoped”.

## Pricing Journal
- [ ] Production-first Cost Plus math present (painter-days → labor anchor → solve P).
- [ ] Fee mode correct (STD vs RealVitalize).
