# Handyman — Default Install Times (Draft)

Purpose: give Mac a repeatable baseline for FastField-driven handyman scope builds.

**Defaults (starting points, adjust with notes):**
- Install light fixture (standard / flush mount): **45 min**
- Replace vanity strip light fixture: **60 min**
- Install ceiling fan (standard): **75 min** *(60–90 depending on complexity)*
- Mirror swap / replace panel mirror: **45 min**
- Hardware swap (knob/deadbolt like-for-like): **30–45 min**
- Cabinet face repair (default allowance when notes are vague): **90 min**
  - Finished condition assumption: secure + presentable from 3–5 feet; finish matching not guaranteed.
- Budget blocks (e.g., handrail repair): use explicit hours (e.g., **2.0 hrs**) when provided.

Rules:
- Billing rates:
  - Default customer handyman rate: **$100/hr**
  - **RealVitalize exception:** default customer handyman rate: **$120/hr** (unless Luke specifies $125)
  - Internal handyman labor cost baseline: **$50/hr** (subcontractor)
- If FastField task dropdowns are missing (known glitch in some rooms), use `handyman_handyman_notes` as authoritative and map notes → one or more tasks + minutes.
- Output requirements in Proposal Pack:
  - Labor estimate (hours + $)
  - Scope list (walkthrough order)
  - Copy/paste minutes list (line breaks)
  - Copy/paste allowance list
  - PandaDoc-ready SCOPE DETAILS + standard handyman terms
- **Alignment rule:** SCOPE DETAILS bullets must match the minutes list 1:1 (same count, same order). Prefer one bullet per task (repeat room name as needed).
