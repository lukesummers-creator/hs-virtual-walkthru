# HOMEstretch Handyman Library — v0 (Draft)

Purpose: quick lookup for common handyman tasks (labor time expectations + typical materials allowances) so quotes are faster and more consistent.

**Pricing method (default):** sell handyman at **$100/hr** (labor). Typical payout target $60/hr.

**Materials:** client typically purchases. HOMEstretch can provide a free purchase list/links. If HOMEstretch purchases and delivers materials, add **17% service fee** to materials.

## Common tasks

### Light fixture swap — standard flush mount (like-for-like)
- **Labor:** 0.5 hr (30 min)
- **Materials allowance (if needed):** $22 (misc hardware/wire nuts/consumables) — *fixture usually client-supplied*
- **Assumptions / caveats:** Like-for-like swap on existing box; no drywall repair/patch/paint included.

### Light fixture swap — fluorescent to LED panel (like-for-like)
- **Labor:** TBD (needs standard) *(suggest: 0.75–1.0 hr depending on ceiling/box/opening)*
- **Typical fixture allowance:** ~$90 + sales tax (example: 4'×2' LED flat panel)
- **Assumptions / caveats:** Like-for-like replacement; no ceiling modification, patching, or painting included. If box/opening/wiring requires changes, quote as additional work.

### Light fixture swap — LED wraparound (4 ft)
- **Labor:** 0.75 hr (45 min)
- **Typical fixture allowance:** ~$40 + sales tax
- **Assumptions / caveats:** Like-for-like; no drywall patch/paint.

### Cabinet hardware swap (handles/pulls) — like-for-like
- **Labor:** rule of thumb 2–3 min each + setup; typical quote for 25 handles: **1.5 hr**
- **Materials:** client-supplied hardware
- **Assumptions / caveats:** Like-for-like locations; if re-drilling/realignment is needed, time may increase.

### Bifold closet door — top guide/track repair
- **Labor:** 1.0 hr
- **Materials:** attempt to reuse; if parts are stripped/broken and require replacement, notify client.

### Builder-grade vanity strip light → vanity fixture replacement (risk item)
- **Labor (baseline):** 1.0 hr (like-for-like)
- **Materials:** client-supplied fixture (example allowance: $50–$60 + sales tax)
- **Critical caveat:** Strip lights can hide improper wiring/junction box placement. If a centered box is missing and wiring must be extended or a box relocated, additional labor + patch/paint may be required; proceed only with client approval.

### Mirror replacement (builder-grade panel mirror → framed mirror) (risk item)
- **Labor (baseline):** 1.5 hr
- **Materials:** client-supplied mirror (example allowance: $180–$200 + sales tax)
- **Critical caveat:** Removal can reveal wall damage/adhesive requiring skim/patch and repaint. If additional patch/paint is needed beyond touch-up, quote as additional work.

### Dishwasher / end-panel correction (one-off)
- **Labor (baseline):** 2.5 hr
- **Materials:** attempt to reuse existing; if end panel/hardware requires replacement, notify client.
